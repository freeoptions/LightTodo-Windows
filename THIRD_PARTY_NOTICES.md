# Tasks icon attribution

The LightTodo Windows application icon is adapted by resizing the Tasks icon from
[HeyPuter/everything](https://github.com/HeyPuter/everything).

- Upstream revision: `b5d25841527e2b772eb34a80d4973c6bc1dc67c1`
- Original asset: https://github.com/HeyPuter/everything/blob/b5d25841527e2b772eb34a80d4973c6bc1dc67c1/src/tasks/icon.png
- Original artwork is retained in `src-tauri/icon-artwork.png` and `src-tauri/icon-source.png`.
- Colors, aspect ratio and transparency are preserved. No AI redraw was used.
- Windows ICO and PNG resources and `public/icon.png` are resized derivatives.
